## 6. Rules / lessons (2026-09-14)

| Rule                              | Detail                                                                                                                                                       |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Ledger check per deploy target    | check applied migrations on **every** project a branch deploys to — mainnet prd was 10 migrations behind, caused the `/v1/servers` + jobs-sweep 500 incident |
| Doppler write vs Vercel Sensitive | writing a Doppler secret over a Vercel Sensitive row disables that sync; clear/delete the row first                                                          |
| `phala cvms list`                 | hides CVMs sharing an app id; use `phala api /cvms/<uuid>`                                                                                                   |
| `render-fleet.py`                 | never re-harvests `pinned.instanceId`; a stale value bricks the node (fail-closed check) — seed from live values before signing                              |
| One-owner budget                  | production smokes need a `MAINNET_OWNER_BUDGET` guard — a dry run once exceeded it, leaving 2 throwaway Lite owners live on mainnet (#18)                    |
| Canonical-host opt-in             | driver defaults to preview hosts; canonical runs need explicit `ALLOW_CANONICAL=1` + explicit origins                                                        |
